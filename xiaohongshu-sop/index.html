教程 SOP：从下载 WorkBuddy 到用它运营小红书

实体/个体商家零基础版 · 每一步都写到“点哪里、输什么”，照着做就能发第一篇笔记。本教程本身也可作为你训练营的学员手册。

0准备清单（开始前 5 分钟搞定）

设备
一台电脑（Win10 以上 / macOS 12 以上）+ 一部手机（发小红书用）
材料
门店照片 5–10 张、门店/产品视频 1–2 段、店名/地址/主打产品
账号
手机号（注册 WorkBuddy）+ 小红书账号（建议升专业号/企业号）
不用会写代码、不用会设计。全程你只做“提供门店素材 + 最后把关”，其余交给 WorkBuddy。

1下载并安装 WorkBuddy

1.1 打开电脑浏览器（Chrome / Edge / Safari 都行），在地址栏输入 https://www.workbuddy.cn ，按回车。
1.2 在官网首页找到「下载」按钮（通常在首屏或右上角），点击它。
1.3 按你的电脑系统选安装包：
· macOS 电脑 → 点 .dmg（或 .pkg）
· Windows 电脑 → 点 .exe
1.4 下载完成后安装：
· macOS：双击 .dmg，把 WorkBuddy 图标拖进「应用程序」文件夹，再打开启动台双击启动。
· Windows：双击 .exe，安装向导里一直点「下一步 / 安装」，完成后桌面出现 WorkBuddy 图标，双击打开。
1.5 首次启动 → 用手机号注册 / 登录（收验证码）→ 登录成功进入主界面。
需要联网才能用 AI 能力；如果打不开官网，检查网络或稍后重试，以官网实际页面为准。

2认识主界面（记住这 3 块就够）

左侧 · 任务栏
显示你的任务列表（按文件夹分组），底部是你的头像；从这里进「专家」中心、在右上角进「连接器」管理。
中间 · 对话区
核心区域：顶部任务标题栏、中间消息列表、底部输入框——你在这里跟它说话下指令。
右侧 · 结果区
它生成的文档 / 图片 / 文件都在这里，可预览、可下载，是你的“产出仓库”。
工作模式：默认 Craft（你说我做） 即可；想先商量方案选 Plan；只想问问题选 Ask。新手全程用 Craft 最省事。

3第一次对话：让 WorkBuddy 记住你的店

把店的基础信息一次性告诉它，以后做选题/文案/封面它都按你的店来，不用重复说。

3.1 在底部输入框，复制下面这段，把【括号】里改成你的真实信息，回车发送：
我是开【奶茶店】的老板，店在【成都·春熙路】，主打【鲜果茶】，
想用小红书把附近3公里的人引到店。请记住这些信息，
以后帮我做选题、文案和封面图，都按这家店的定位来。
3.2 它会回复确认，并把信息记到长期记忆里。
3.3 （推荐）再发一句：“把上面这些信息整理成一份「店铺档案」，存到文件里，方便以后调用。” → 右侧结果区会出现一个文件，以后直接说“按店铺档案来”就行。

4用 WorkBuddy 找本地热门选题（联网搜索）

4.1 在输入框复制下面这段，改【括号】内容，回车：
帮我联网搜一下最近【成都】【奶茶/饮品】在小红书上的热门选题
和本地流量方向，给我10个适合实体店发的选题，
按“探店 / 种草 / 活动 / 避坑”分类，并标注每个选题为什么能引到店。
4.2 它会联网返回一份选题清单 → 你挑 3 个 作为本周要发的。
4.3 把选中的告诉它：“就把第 1、3、5 个写成标题，每个给 5 个备选标题。” → 它出标题供你选。
不会挑？直接问它：“这 3 个里哪个最适合新店冷启动、最容易爆？”让它帮你排优先级。

5生成笔记文案

5.1 复制下面这段，把【选题】换成你选的，回车：
按选题【成都春熙路奶茶探店】，给我写一篇小红书图文笔记：
· 标题 5 选 1
· 正文 300 字以内，口语化，像老板自己跟邻居聊天
· 带 5 个话题标签（含#成都奶茶 #春熙路）
· 结尾加一句引导到店的评论钩子（如“评论领买一送一”）
· 文末提醒我填店名、地址、优惠
5.2 它产出后，你可以直接复制用；也可以让它“存成文件”，右侧结果区下载。
5.3 把店名、地址、真实优惠填进正文空白处，文案就定了。
文案是 AI 写的，发布前一定亲自读一遍、把优惠/地址改成真实的，别发出错的券。

6生成封面图（图像生成）

6.1 复制下面这段，改【标题/产品】，回车：
帮我生成一张小红书封面图：3:4 竖图，红橙配色，
大字标题“【成都奶茶控必看】”，
背景是诱人的鲜果茶杯特写，风格干净明亮，像门店促销海报。
6.2 等待生成（几十秒）→ 在右侧结果区预览，点下载 / 右键保存图片到电脑。
6.3 想一次出同风格多张：“保持这个视觉风格，再生成 3 张，标题分别换成【XX】【XX】【XX】。” → 一套封面就齐了。
封面要“大字 > 图”，前 0.5 秒抓人。固定一套配色字体，账号才有“视觉锤”，粉丝刷到就知道是你。

7生成短视频（可选，吃视频流量）

7.1 先让它写口播脚本：
把第5步的笔记改成 30 秒口播脚本：第1句钩子吸引看完，
中间展示门店/产品，结尾引导到店，标注画面建议。
7.2 再发：“用这段脚本生成一段 30 秒门店短视频（配门店画面/字幕）。” → 生成后右侧结果区下载。
7.3 把视频发到小红书「视频笔记」，图文号也能吃视频流量。
视频生成会消耗额外额度，新手先用图文跑通流程，再上视频。

8发布到小红书（你来做，WorkBuddy 出素材）

8.1 打开手机小红书 APP → 点底部中间的「＋」→ 从相册选 WorkBuddy 生成的封面 + 门店图（3–6 张）。
8.2 填标题（用第 5 步的）、正文（粘贴，确认优惠/地址已填真）、加话题标签。
8.3 ⭐关键一步：点「添加地理位置」→ 搜你店名/地址打标签。这是同城流量的核心，实体店必做。
8.4 如有团购：绑定「门店 / 团购」组件，让用户直接买券到店核销。
8.5 发布时间选：早 7:30–9:00 / 午 12:00–13:00 / 晚 20:00–22:30；周三、四、日通常更好。
8.6 发后 2 小时内：亲自回前 20 条评论，并置顶一条“评论领优惠 / 看店铺档案”的钩子。
回评论不是客套，是涨粉和到店的关键动作。WorkBuddy 能写回复话术，但你本人出镜/口吻更可信。

9设置自动化排期 + 每周复盘

9.1 让 WorkBuddy 替你“记着发”

在输入框复制这段，回车，它会创建定时任务：
请帮我创建一个自动化：每周一、三、五 早上9点 提醒我——
今天要发的小红书选题是什么、封面和文案是否用 WorkBuddy 做好了、
记得打地理位置标签、发后2小时回评论。语气像同事提醒。
以后不用自己记排期，到点在 WorkBuddy 里自动弹提醒。想改频率，直接说“改成每周发4次”即可。

9.2 每周数据复盘

9.2.1 打开小红书「创作中心 → 数据」，记下：小眼睛（曝光）、赞藏评、新增粉丝、最火的一篇。
9.2.2 把数据发给 WorkBuddy：
这是我这周的小红书数据（小眼睛XX、赞藏评XX、新增粉XX），
最火的是【XX篇】。帮我分析哪类笔记引到店效果最好，
下周该加什么、砍什么，给一份周报。
9.2.3 它出复盘 → 照建议调下周选题，形成“发 → 看数据 → 优化”的飞轮。

B附录 B：复制粘贴提示词库

找选题

联网搜【城市】【行业】小红书热门选题，给10个，按探店/种草/活动/避坑分类，标注为何能引到店。

写文案

按选题【XX】写小红书图文：标题5选1 + 正文300字内（口语化）+ 5个标签 + 到店钩子。

做封面

生成小红书封面 3:4 竖图，红橙配色，大字标题【XX】，背景【产品】特写，门店海报风。

做视频

把笔记改成30秒口播脚本（钩子+展示+引导到店），再生成30秒门店短视频。

周复盘

这是我本周数据（小眼睛XX、赞藏评XX、新增粉XX），最火【XX篇】，分析哪类引到店最好，下周加什么砍什么，给周报。

自动化

创建自动化：每周一三五早9点提醒我今日选题、封面文案是否做好、记得打地理标签和回评论。

C附录 C：常见问题

  • 下载打不开？ 检查网络；确认系统是 Win10 / macOS 12 以上；以官网 workbuddy.cn 为准。
  • 生成的文案要改吗？ 必须改——把店名、地址、优惠填成真实的再发，别发错券。
  • 图片能商用吗？ 用于自己门店宣传一般可用，正式商用前确认生成内容的版权说明。
  • 没流量怎么办？ 先检查是否打了地理位置标签、封面是否大字抓人；用第 9 步复盘调选题。
  • 要请人运营吗？ 按本 SOP，老板自己每天 20 分钟就能跑通，省下运营工资。
